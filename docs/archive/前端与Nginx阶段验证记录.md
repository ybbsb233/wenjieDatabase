# 前端与 Nginx 阶段验证记录

日期：2026年10月19日

## 完成内容

完成原生 HTML、CSS、JavaScript 前端，共 13 个页面。学生端覆盖登录、首次改密、课程首页、练习设置、答题、结果、历史、错题重练和薄弱项；管理员端覆盖整体统计、学生管理、学生详情及其练习与错题查看。

采用深绿导航、浅色内容区和课程卡片，使用 CSS 条形图、原生 SVG 趋势图。没有引入前端框架、构建工具或图表依赖。题目、姓名与解析使用转义文本呈现。

使用本机已有的 Nginx 1.22.0，配置独立运行目录，不修改原有 Nginx 配置。Nginx 提供前端文件，并将 /api/ 请求代理到 Spring Boot。测试端口为前端 18081、后端 18080，仅监听本机回环地址。

增加 start-site.ps1、stop-site.ps1，支持同时启停本项目后台服务；也保留单独启动前后端的脚本。数据库密码和 JWT 密钥通过环境传入，不保存到前端或配置文件。
