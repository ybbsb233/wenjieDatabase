# 固定章节练习重构记录

日期：2026年10月19日

## 当前效果

五门课程均设置五个当前章节，每章二十道题，共二十五套固定练习、五百道题。每章两个知识点，每个知识点十道题；每章包含十道单选、四道多选、六道判断。章节目录见固定练习题库目录.md。

开始练习页面默认打开固定章节练习，可切换课程查看五套练习的完成次数、最近成绩和历史结果。相邻的自主随机练习保留范围筛选和题量设置。

固定练习对所有学生使用相同题目及相同题序，单选和多选的选项独立随机排列；判断题保持正确、错误顺序。再次开始会生成新的作答记录，不覆盖上次结果。
